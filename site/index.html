The Kubernetes desktop app that never makes you wait

Kompass is a fast, native Kubernetes client built in Rust — a lightweight alternative to Lens. Browse pods, tail logs, exec into containers and edit YAML across all your clusters, in a UI that stays instant on clusters of any size.

Download for Mac Star on GitHub
brew install --cask erango/tap/kompass

Universal build (Apple Silicon + Intel) · Signed & notarized · Updates itself · MIT

Everything you reach for, without the weight

One small native binary. All cluster I/O runs on a background runtime, so the interface never blocks on the network — not even while reconnecting.

Fast on big clusters

Live watches, virtualized tables and stale-while-revalidate caching. Thousands of pods scroll smoothly.

Every kind, every CRD

Discovery-driven: all built-in resources and custom resources, grouped in a clean sidebar.

Live metrics

CPU and memory per pod with sparklines, sortable columns, and per-container status at a glance.

Logs that behave

Follow, wrap, include/exclude filters, ANSI colors, and merged multi-pod streams.

Exec & YAML

An interactive terminal into any container, and a syntax-highlighted, searchable YAML editor.

Keyboard-first

⌘K jumps to any kind, cluster or resource. Back/forward history with ⌘[ ⌘].

Multi-cluster

Switch and pin clusters, keep per-cluster namespace views, and work with namespace-scoped access.

Self-healing auth

Expired EKS / GKE / OIDC credentials refresh automatically — no relaunch after you SSO.

Operate safely

Restart rollouts, scale, cordon and drain, port-forward and delete — with confirmation for destructive actions.

See it in action

Dark and light themes, a calm design system, and native macOS window integration.
